# Finance Sheets Formula Lab

A single-page visual web app that teaches the most useful Google Sheets formulas for operating finance and accounting teams.

## Preview the app (recommended)

Some browsers block or behave inconsistently with `file://` URLs, so use a local web server.

From the repository root (`/workspace/agents-towards-production`), run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/tutorials/google-sheets-finance-formulas-webapp/
```

## Alternative preview commands

If you prefer a different port:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173/tutorials/google-sheets-finance-formulas-webapp/
```
